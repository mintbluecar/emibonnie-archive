# Security policy

## Reporting a vulnerability

Please report security issues privately through [GitHub Security Advisories](../../security/advisories/new) on this repository. Do not open a public issue for a security report.

We'll acknowledge the report and follow up with next steps. Please include enough detail to reproduce the issue (affected endpoint or module, steps, and impact).

## Scope

This policy covers the engine in this repository. A site built from this template is responsible for its own deployment security (secrets, access control, hosting configuration).
